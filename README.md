# theHelixProtocol 🧬

> **Obsidian-style 3-column knowledge management and research system.**

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Python](https://img.shields.io/badge/Python-3.10-blue.svg)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow.svg)

theHelixProtocol is a local-first knowledge management system designed for researchers and power users. It features a unique 3-column UI for simultaneous viewing of notes, references, and research threads.

## ✨ Features
- **3-Column UI:** Optimized for research-heavy workflows.
- **Local-First:** Your data stays on your machine.
- **Markdown Support:** Full compatibility with Obsidian-style markdown.
- **Research Tracking:** Link thoughts, citations, and documents seamlessly.

## 🛠️ Tech Stack
- **Backend:** Python (Data processing)
- **Frontend:** JavaScript / CSS (UI Layout)
- **Database:** Local-first file system storage

## 🚀 Installation
```bash
# Clone the repository
git clone https://github.com/TheClairvoyantBeing/theHelixProtocol.git
cd theHelixProtocol

# Install dependencies
npm install
```
